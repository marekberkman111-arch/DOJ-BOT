# San Andreas – hybridní RP právní systém

**Schválený směr:** kalifornské právo jako inspirace + originální pravidla San Andreas RP.

## Zásady
1. **Žádné vydávání RP paragrafů za skutečné kalifornské právo.**
2. Každý předpis má vlastní zkratku, číslo, stav, verzi a datum účinnosti.
3. Návrhy jsou oddělené od schválených a účinných dokumentů.
4. Schválení zákona musí respektovat pravomoci Government; soudci nerozhodují o politickém schválení zákonů.
5. Zrušení nebo novela nezničí historii předchozích verzí.
6. RP sankce (minuty vězení, herní dolary) vyžadují schválení pravidly serveru.

## Katalog
| Kód | Předpis | Kalifornská inspirace |
|---|---|---|
| UST | Ústava San Andreas | dělba moci |
| TZ | Trestní zákoník | California Penal Code |
| TR | Trestní řád | procesní ustanovení kalifornského práva |
| SR | Soudní řád | California Rules of Court |
| OP | Občanské právo | California Civil Code |
| DP | Dopravní předpisy | California Vehicle Code |
| PS | Pravomoci státních složek | zásady veřejné správy |
| VG | Vládní a legislativní řád | legislativní proces |

Toto je struktura, **nikoli přepis ani právní ověření aktuálních kalifornských ustanovení**.
Konkrétní odkazy na reálné paragrafy budou ověřeny zvlášť před zveřejněním.

## Publikování
- `/pravni_predpis` – zobrazí strukturu a stav předpisu.
- `/publikovat_zakonik` – administrátor zveřejní *návrhový index* do určeného kanálu.
- `/vyhlaska` → `/schvalit_vyhlasku` – stávající workflow návrh/schválení.
- Veškerá legislativa je Discord embed; žádné PDF.
- Webhooky lze připojit pomocí Railway Variables, nebo se použije odeslání botem.

## Otevřené úkoly
Schvalování zákonů a novel, účinnost, historie verzí, databázové migrace, skutečná publikace předpisů,
vyladění rolí a integrační testy. Návrhový index **není** účinným zákonem.
